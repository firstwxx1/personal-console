# 个人控制台

个人使用的深色控制台 UI Prototype，用于管理 VPS、项目、服务网站和技术笔记。

## 当前阶段

第一阶段已完成：

- Next.js + TypeScript + Tailwind CSS 基础结构
- 深色优先的设计令牌，并预留浅色主题变量
- shadcn/ui 风格组件基础与路径配置
- Lucide Icons
- 基础 Button、Card、Badge、Progress、StatusBadge 组件
- ESLint、TypeScript、Next.js 脚本
- 设计系统验证页

尚未开发全局 Sidebar、业务页面、Mock Data 和全局搜索。

## 本地运行

```bash
npm install
npm run dev
```

打开 <http://localhost:3000>。

## 检查命令

```bash
npm run lint
npm run typecheck
npm run build
```
